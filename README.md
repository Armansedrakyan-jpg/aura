# Aura Battle ⚔️ — AI-Powered Real-Time Multiplayer Mobile App

A modern, high-performance, and beautifully designed full-stack mobile application where players analyze their "aura" using Google Gemini AI and battle against other users in real-time lobbies!

## 🚀 Tech Stack

- **Mobile Client:** Native Android (Kotlin, Jetpack Compose, Retrofit 2, Coroutines, StateFlow, Coil)
- **Backend Server:** Java 21, Spring Boot, Spring Security (JWT-based), Docker
- **Databases:** Aiven MySQL (Persistent history), Firebase Realtime Database (Ultra-low latency live match syncing)
- **AI Engine:** Google Gemini Developer API (Generative Language)

## ✨ Key Features

- **AI Aura Analysis:** Users upload a photo and get a custom aura score (0-100) and hilarious TikTok-styled viral titles (e.g., *GigaChad*, *Sigma*, *NPC*) generated by Gemini AI.
- **Real-Time Duels:** Instant 6-digit PIN-code matchmaking lobbies synced via Firebase WebSockets.
- **Global Leaderboard:** Glowing neon-styled TOP-100 rankings fetched dynamically from MySQL.
- **Secure & Production-Ready:** No hardcoded secrets. Fully configured via environment variables.

## 📦 How to Deploy in 5 Minutes on Render & Aiven

1. **Database:** Create a free MySQL database on Aiven.
2. **Backend:** Connect this GitHub repository to Render (Web Service), select **Docker** as environment.
3. **Configure Environment Variables on Render:**
   - `SPRING_DATASOURCE_URL` = `jdbc:mysql://<Aiven_Host>:<Aiven_Port>/defaultdb?sslMode=REQUIRED&allowPublicKeyRetrieval=true`
   - `SPRING_DATASOURCE_USERNAME` = `avnadmin`
   - `SPRING_DATASOURCE_PASSWORD` = `<Aiven_DB_Password>`
   - `GEMINI_API_KEY` = `<Your_Google_Gemini_Key>`
   - `JWT_SECRET` = `<Your_Secure_JWT_Secret>`
   - `FIREBASE_CREDENTIALS_JSON` = `<Your_Firebase_Service_Account_JSON_Content>`
4. **Android Client:** Update `BASE_URL` in `RetrofitClient.kt` with your Render URL, build the APK, and enjoy!
